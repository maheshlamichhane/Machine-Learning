Logistic Regression
-> predict a categorical dependent variable from a number of independent variables.
-> Example will purchase health insurance yes/no. age,income,family/single,level of edu is independent variable.

Logistic Regression is a Supervised Machine Learning algorithm used for Classification problems.

Although its name contains the word Regression, it is primarily used to predict categories or classes rather than
continuous numerical values.

Let's understand it step by step with simple examples.
1. What is Logistic Regression?
Suppose you want to build a machine learning model that predicts whether a student will pass or fail an
 examination based on the number of hours they study.

Your training dataset looks like this:
Study hours	Result
1	Fail (0)
2	Fail (0)
3	Fail (0)
4	Pass (1)
5	Pass (1)
6	Pass (1)
7	Pass (1)

You want your machine learning model to predict whether a new student who studies for 3.5 hours will pass or fail.

This is a classification problem because the output belongs to one of two categories:
- 0 = Fail
- 1 = Pass
Logistic Regression learns the relationship between study hours and the probability of passing.

For example:
- 1 hour → 10% probability of passing.
- 3 hours → 30% probability of passing.
- 5 hours → 80% probability of passing.
- 7 hours → 95% probability of passing.
The model then converts that probability into a class prediction.
2. Why can't we use Linear Regression?
This is one of the most important concepts to understand.

Linear Regression predicts continuous numerical values.

For example:
\[
y = b_0+b_1x
\]

If we use Linear Regression to predict whether a student passes or fails, the output could be:
- 1.2
- 0.8
- -0.5
- 1.5
But our classification output should be either 0 or 1.

Linear Regression can produce values outside the range of 0 and 1, which are not valid probabilities.

Logistic Regression solves this problem by using the Sigmoid function.
3. Understanding the Sigmoid Function
The Sigmoid function is the most important part of Logistic Regression.

It converts any numerical input into a value between 0 and 1.

Its mathematical formula is:
\[
P(Y=1)=\frac{1}{1+e^{-z}}
\]

Where:
\[
z=b_0+b_1x_1+b_2x_2+\cdots+b_nx_n
\]

Here:
- \(P(Y=1)\) = Probability that the output belongs to class 1.
- \(e\) = Euler's mathematical constant (approximately 2.718).
- \(b_0\) = Intercept.
- \(b_1,b_2,\ldots\) = Model coefficients.
- \(x_1,x_2,\ldots\) = Independent variables.
The Sigmoid function produces an S-shaped curve.

K-NN Regression Model
K-Nearest Neighbors (KNN) Algorithm – Explained Simply
K-Nearest Neighbors (KNN) is a Supervised Machine Learning algorithm used for both Classification and
Regression problems.

The main idea behind KNN is very simple:

"Similar things are usually found near each other."

KNN predicts the output of a new data point by looking at the closest existing data points (neighbors).

Let's understand it with a real-world example.
1. What is KNN?
Suppose you have a dataset containing information about different fruits.
Fruit	Weight (grams)	Sweetness
Apple	150	4
Apple	170	5
Apple	160	4
Orange	130	7
Orange	140	8
Orange	120	7

Now, somebody gives you a new fruit:
- Weight = 155 grams
- Sweetness = 5
You don't know whether it is an Apple or an Orange.

KNN compares this new fruit with the existing fruits and finds the nearest neighbors.

Suppose the nearest 3 fruits are:
- Apple
- Apple
- Orange
Since Apple appears most frequently, KNN predicts:
Prediction: Apple
This is called majority voting.
2. How does KNN work?
KNN follows these steps:
Step 1: Load training dataset

Collect existing data with known labels.


Step 2: Choose K

Decide how many nearest neighbors to consider.


Step 3: Calculate distances

Measure the distance between the new data point and existing data points.


Step 4: Find K nearest neighbors

Select the closest K data points.


Step 5: Make prediction

Classification: majority vote. Regression: average value.


3. What does K mean in KNN?
K represents the number of nearest neighbors used to make a prediction.

For example:

Suppose K = 3.

The algorithm considers the 3 closest data points.
Neighbor	Predicted category
Neighbor 1	Apple
Neighbor 2	Apple
Neighbor 3	Orange

Final prediction = Apple.

Now suppose K = 5:
Neighbor	Predicted category
Neighbor 1	Apple
Neighbor 2	Apple
Neighbor 3	Orange
Neighbor 4	Orange
Neighbor 5	Apple

Final prediction = Apple.

The algorithm chooses the category with the most votes.

Important: For binary classification, an odd K is often selected to reduce ties, although ties can still occur with multiple classes.
4. How does KNN calculate distance?
This is one of the most important parts of KNN.

KNN needs to calculate the distance between data points to identify the nearest neighbors.

There are several distance measurement methods.
A. Euclidean Distance
Euclidean distance is the most commonly used distance measurement in basic KNN.

It calculates the straight-line distance between two points.

Formula for two dimensions:
\[
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}
\]

For multiple dimensions:
\[
d=\sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}
\]

Let's take an example.

Point A = (2, 3)

Point B = (5, 7)
\[
d=\sqrt{(5-2)^2+(7-3)^2}
\]

\[
=\sqrt{9+16}
\]

\[
=\sqrt{25}=5
\]

Therefore, the distance between A and B is 5.
B. Manhattan Distance
Manhattan distance calculates the distance by moving horizontally and vertically, like travelling through city streets.

Formula:
\[
d=|x_2-x_1|+|y_2-y_1|
\]

Using the same points:

A = (2, 3)

B = (5, 7)
\[
d=|5-2|+|7-3|
\]

\[
=3+4=7
\]

Euclidean distance = 5.

Manhattan distance = 7.

Other distance methods include Minkowski distance and Hamming distance. The appropriate method depends on the type of data.
5. Types of KNN
KNN can solve two types of problems.

A. KNN Classification

Used when the output is a category or class.

Examples:
- Spam / Not Spam
- Pass / Fail
- Apple / Orange
- Fraud / Not Fraud
It uses majority voting to determine the final class.

B. KNN Regression

Used when the output is a continuous numerical value.

For example, predicting house prices.

Suppose the nearest 3 houses have these prices:
Neighbor	House price
House 1	Rs. 50 lakh
House 2	Rs. 60 lakh
House 3	Rs. 70 lakh

KNN Regression calculates the average:
\[
Prediction=\frac{50+60+70}{3}
\]

\[
\boxed{Prediction=60\text{ lakh}}
\]

So, the predicted house price is Rs. 60 lakh.
Difference between KNN Classification and Regression
Classification	Regression
Predicts categories	Predicts numbers
Uses majority voting	Uses average
Output: Apple	Output: Rs. 60 lakh


6. Why is Feature Scaling important in KNN?
This is a very important concept, especially when implementing KNN in Python.

Suppose your dataset contains:
Feature	Value
Age	30
Salary	100,000

Here, Age ranges from approximately 18–60, while Salary can range from 20,000–200,000.

KNN calculates distances using these features.

Because Salary has much larger numerical values, it can dominate the distance calculation.

As a result, Age might have very little influence on the prediction.

Solution: Feature Scaling

We normalize or standardize the features so they are on comparable scales.

Two common techniques:

A. Standardization
\[
z=\frac{x-\mu}{\sigma}
\]

Where:
- \(x\) = Original value.
- \(\mu\) = Mean.
- \(\sigma\) = Standard deviation.
B. Normalization (Min-Max Scaling)
\[
x'=\frac{x-x_{min}}{x_{max}-x_{min}}
\]

This generally transforms values into a range between 0 and 1.

Support Vector Machine (SVM)
Support Vector Machine (SVM) is a Supervised Machine Learning algorithm used for both Classification and
 Regression problems.

The main idea behind SVM is:

Find the best possible boundary that separates different classes of data.

Let's understand it with a simple example.
1. What is SVM?
Suppose you have information about two types of fruits:
- Apples (Red points)
- Oranges (Blue points)
You want to build a machine learning model that can identify whether a newly introduced fruit is an Apple or
 an
Orange.

You have two features:
- X-axis = Weight
- Y-axis = Sweetness
SVM looks at the existing data and tries to find a boundary (line) that separates the two categories.








colab.research.google.com


This separating boundary is called a Hyperplane.

For a two-dimensional dataset, the hyperplane is a line.

For a three-dimensional dataset, it is a plane.

For higher-dimensional datasets, it is called a hyperplane.
2. What makes SVM different from other algorithms?
Let's compare it with Logistic Regression.

Both algorithms can classify data into two categories, but they approach the problem differently.










Logistic Regression

Finds a linear decision boundary by optimizing likelihood (or minimizing log loss).











SVM

Finds a decision boundary that maximizes the margin between classes.


The most important difference:
- Logistic Regression focuses on estimating class probabilities.
- SVM focuses on finding a boundary with the maximum margin.
3. Understanding Hyperplane, Margin and Support Vectors
These are the three most important concepts in SVM.
A. Hyperplane
A hyperplane is the decision boundary that separates different classes.

For two-dimensional data, the equation of a line is:
\[
w_1x_1+w_2x_2+b=0
\]

Where:
- \(w_1,w_2\) = Model weights.
- \(x_1,x_2\) = Input features.
- \(b\) = Bias.
B. Margin
Margin is the distance between the decision boundary and the nearest data points from each class.

SVM tries to maximize this margin.

Why?

Because a larger margin generally helps the model generalize better to unseen data.








mdpi.com


C. Support Vectors
Support vectors are the data points closest to the decision boundary.

They are extremely important because they determine the position of the optimal separating hyperplane.

For example:

Suppose you have 100 data points.

Only a few points closest to the boundary may determine the final SVM decision boundary.

Those points are called Support Vectors.

Remember:
- Hyperplane = Separating boundary.
- Margin = Distance between boundary and nearest points.
- Support Vectors = Nearest data points that help determine the boundary.
4. How does SVM work?
SVM follows these general steps:
Step 1: Load training dataset

Input features and their class labels.


Step 2: Identify possible separating boundaries

Find boundaries that separate the classes.


Step 3: Find support vectors

Identify the closest points to the boundary.


Step 4: Maximize the margin

Choose the optimal separating hyperplane.


Step 5: Predict new data

Classify new observations using the learned boundary.


5. What if data cannot be separated using a straight line?
This is where SVM becomes interesting!

Suppose your dataset contains two classes that are mixed together in a way that no straight line can separate them.

A simple linear boundary will not work well.

SVM handles this using something called the Kernel Trick.
Understanding the Kernel Trick
Imagine you have data arranged in a circular pattern:
- Class A points are in the center.
- Class B points surround Class A.








medium.com


You cannot separate these two classes properly using a straight line in the original two-dimensional space.

But SVM can use a kernel function to represent the data in a higher-dimensional feature space, where a linear separating boundary may become possible.

This is called the Kernel Trick.

In simple words:

The Kernel Trick helps SVM solve non-linear classification problems by implicitly working in a higher-dimensional feature space.
6. Types of Kernel Functions in SVM
A kernel function helps SVM handle different types of data relationships.

There are four commonly used kernels.
A. Linear Kernel
Used when data can be separated using a straight line or hyperplane.
\[
K(x,y)=x^Ty
\]









askfilo.com


Example: Classifying emails into spam and not spam when the features are approximately linearly separable.
B. Polynomial Kernel
Used when the relationship between data points is more complex and can be represented using polynomial
interactions.
\[
K(x,y)=(\gamma x^Ty+r)^d
\]

Where:
- \(\gamma\) = Kernel coefficient.
- \(r\) = Constant term.
- \(d\) = Polynomial degree.








medium.com


C. RBF (Radial Basis Function) Kernel
This is one of the most commonly used kernels in SVM.

It can handle complex non-linear relationships.
\[
K(x,y)=e^{-\gamma ||x-y||^2}
\]









mathworks.com


The RBF kernel measures similarity between data points.
- Nearby points have higher similarity.
- Faraway points have lower similarity.
D. Sigmoid Kernel
The sigmoid kernel uses a hyperbolic tangent function.
\[
K(x,y)=\tanh(\gamma x^Ty+r)
\]

It resembles the activation function used in neural networks.

It is less commonly used than the RBF kernel.
Quick comparison
Kernel	Best suited for
Linear	Approximately linearly separable data
Polynomial	Polynomial relationships
RBF	Complex non-linear relationships
Sigmoid	Certain neural-network-like representations

7. Important SVM Hyperparameters
When implementing SVM, you will frequently encounter three important parameters.
A. C (Regularization Parameter)
C controls the trade-off between maximizing the margin and minimizing classification errors.

Think of C as how strictly the model tries to classify training data correctly.
- High C: Penalizes misclassification heavily. Tries to classify training examples correctly, potentially resulting in overfitting.
- Low C: Allows more training errors and generally encourages a wider margin, potentially resulting in underfitting.








medium.com


B. Gamma
Gamma is particularly important when using the RBF kernel.

It controls how far the influence of an individual training point extends.
- High Gamma: Each point has a smaller area of influence. The decision boundary can become more complex.
- Low Gamma: Each point has a larger area of influence. The decision boundary becomes smoother.








winder.ai


C. Degree
Degree is used with the polynomial kernel.

It determines the polynomial degree.

For example:
- Degree = 2 → Quadratic relationships.
- Degree = 3 → Cubic relationships.
- Degree = 4 → Fourth-degree relationships.
Higher degrees can create more complex decision boundaries.

Absolutely! In Kernel SVM, the process of classifying a new point is almost the same, but there is one important
 difference: the decision boundary can be non-linear (curved) instead of a straight line.

Let's understand step by step.
1. Why do we need Kernel SVM?
Imagine we have two classes:
- 🟡 Yellow points
- 🔵 Blue points
Suppose the blue points are surrounded by yellow points.








linkedin.com


A straight line cannot separate these two classes properly.

This is where Kernel SVM helps.
2. How does Kernel SVM work?
Kernel SVM uses a mathematical technique called the Kernel Trick.

It allows SVM to handle data that cannot be separated by a straight line in its original feature space.

For example:
1. It uses a kernel function to calculate relationships between data points.
2. This allows it to learn a non-linear decision boundary.
3. It classifies a new point based on which side of that boundary it falls.








medium.com


You don't need to manually transform the data into higher dimensions. The kernel function handles the required
calculations.
3. How is a new point classified?
For a new point \(X\), Kernel SVM uses a decision function:
\[
f(X)=\sum_{i=1}^{n}\alpha_i y_i K(X_i,X)+b
\]

Where:
- \(X_i\) = Training data points (support vectors contribute to the sum).
- \(\alpha_i\) = Learned weights.
- \(y_i\) = Class labels (-1 or +1).
- \(K(X_i,X)\) = Kernel function.
- \(b\) = Bias.
The decision is:
Decision function	Predicted class
Positive	Class +1
Negative	Class -1
Zero	On the decision boundary

So even though the boundary is curved, the classification principle remains the same.

Kernel SVM
What is Kernel SVM (Support Vector Machine)?
First, remember what SVM does:

SVM is a supervised machine learning algorithm used mainly for classification.

Its goal is to find the best decision boundary (hyperplane) that separates different classes of data.

But there is a problem: What if the data cannot be separated using a straight line?

This is where Kernel SVM comes in.
1. Understand the problem with normal SVM
Imagine we have two classes of data:
- Yellow points in the center.
- Purple points surrounding the yellow points.

Can you separate these two classes using a straight line?

No! Because the yellow points are surrounded by purple points.

A normal linear SVM cannot effectively separate them using a straight decision boundary.
2. How does Kernel SVM solve this problem?
Kernel SVM uses something called the Kernel Trick.

The basic idea is:
1. Take the original data (2D).
2. Transform it mathematically into a higher-dimensional space (3D, for example).
3. Find a linear decision boundary in that higher-dimensional space.
4. When viewed in the original space, that boundary becomes nonlinear.


Think of it this way:

In 2D, you cannot separate the points using a straight line.

But after transforming the data into 3D, you might be able to separate them using a flat plane.

When that plane is mapped back to 2D, it creates a curved decision boundary.

That's the main concept of Kernel SVM!
3. What is the Kernel Trick?
The Kernel Trick allows SVM to calculate relationships between data points in a higher-dimensional feature space without explicitly transforming all the data into that space.

In simple words:

Instead of actually converting every data point into 3D or 4D, the kernel function performs the necessary mathematical calculations efficiently.

There are four popular kernel functions:
Kernel	Explanation
Linear	Separates data using a straight line or plane.
Polynomial	Creates curved decision boundaries.
RBF (Gaussian)	Handles complex, nonlinear patterns.
Sigmoid	Uses a sigmoid-shaped mathematical function.

Bayes' Theorem
1. What is Bayes' Theorem?
Bayes' Theorem is a mathematical formula in probability that helps us calculate the probability of an event
based on previously known information or new evidence.

In simple words:

Bayes' Theorem helps us update our belief about something when we receive new information.

For example:
- What is the probability that a person has a disease if their medical test is positive?
- What is the probability that a student passed an exam if they studied?
- What is the probability that a product is defective if it comes from a particular factory?
- What is the probability that it will rain if the sky is cloudy?
Bayes' Theorem is widely used in:
1. Artificial Intelligence (AI)
2. Machine Learning
3. Medical diagnosis
4. Data science
5. Weather forecasting
6. Spam email detection
7. Decision-making systems
2. Understanding probability
Before understanding Bayes' Theorem, let's understand probability.

Probability measures how likely an event is to happen.

The general formula is:
\[
P(A)=\frac{\text{Favourable Outcomes}}{\text{Total Outcomes}}
\]

For example:

Suppose a factory produces 1,000 products, out of which 100 are defective.

The probability of selecting a defective product is:
\[
P(D)=\frac{100}{1000}
\]

\[
P(D)=0.10=10\%
\]

The probability of selecting a non-defective product is:
\[
P(ND)=\frac{900}{1000}
\]

\[
P(ND)=0.90=90\%
\]

Notice that:
\[
P(D)+P(ND)=1
\]

This means the total probability of all possible outcomes is 100%.
3. Bayes' Theorem formula
The mathematical formula is:
\[
\boxed{P(A|B)=\frac{P(B|A)\times P(A)}{P(B)}}
\]

Let's understand each term.
Symbol	Meaning
\(P(A)\)	Prior probability of A
\(P(B)\)	Overall probability of B
\(P(A\|B)\)	Posterior probability of A given B
\(P(B\|A)\)	Likelihood of B given A

1. Prior Probability – P(A)

The probability of an event happening before considering new evidence.

Example: If 20% of products are defective:
\[
P(D)=0.20
\]

2. Likelihood – P(B|A)

The probability of observing evidence B when event A is true.

Example: If a product is defective, a quality inspection correctly identifies it as defective 90% of the time:
\[
P(Positive|D)=0.90
\]

3. Evidence – P(B)

The overall probability of observing evidence B.

Example: The probability of receiving a positive inspection result, whether the product is actually defective or not.

4. Posterior Probability – P(A|B)

The updated probability of event A after observing evidence B.

Example: The probability that a product is actually defective after receiving a positive inspection result.
4. Understanding conditional probability
Conditional probability means calculating the probability of one event when we already know that another event has happened.

Its formula is:
\[
P(A|B)=\frac{P(A\cap B)}{P(B)}
\]

Where:
- \(P(A\cap B)\) = Probability that both A and B happen.
- \(P(B)\) = Probability that B happens.
For example:

Suppose a company has 100 employees:
- 40 employees are developers.
- 20 employees are developers who know Java.
If we randomly select an employee who knows Java, what is the probability that the employee is a developer?

Assume 25 employees in total know Java.
\[
P(Developer|Java)=\frac{20}{25}
\]

\[
=0.80=80\%
\]

This is conditional probability.

Important: Conditional probability and Bayes' Theorem are closely related. Bayes' Theorem uses conditional probability to reverse the condition when we know the opposite probability.

\]

But let's calculate it using the total probability formula.

A defective product can come from either Machine 1 or Machine 2.

Therefore:
\[
P(D)=P(D|M_1)P(M_1)
\]

\[
+P(D|M_2)P(M_2)
\]

Substitute:
\[
P(D)=(0.008333\times0.60)
\]

\[
+(0.0125\times0.40)
\]

\[
P(D)=0.005+0.005
\]

\[
\boxed{P(D)=0.01}
\]

Therefore, the overall defective rate is 1%, as given in the question.
Step 6: Apply Bayes' Theorem
We need to calculate:
\[
P(D|M_2)
\]

The formula is:
\[
P(D|M_2)=
\frac{P(M_2|D)\times P(D)}{P(M_2)}
\]

Substitute the values:
\[
P(D|M_2)=
\frac{0.50\times0.01}{0.40}
\]

\[
=\frac{0.005}{0.40}
\]

\[
=0.0125
\]

Convert to percentage:
\[
0.0125\times100=1.25\%
\]

Final Answer
1.25%
The probability that a randomly selected wrench produced by Machine 2 is defective is 1.25%.


6. Understanding the four probabilities in our machine example
Let's connect our factory example with the four important terms of Bayes' Theorem.
Bayes' term	Probability	Value
Prior	\(P(M_2)\)	40%
Likelihood	\(P(M_2\|D)\)	50%
Evidence	\(P(D)\)	1%
Posterior	\(P(D\|M_2)\)	1.25%

Notice the direction:
- Prior: What is the probability that a product comes from Machine 2?
- Likelihood: Given that a product is defective, what is the probability it came from Machine 2?
- Evidence: What is the overall probability that a product is defective?
- Posterior: Given that a product came from Machine 2, what is the probability it is defective?
This is exactly what Bayes' Theorem does: it reverses conditional probability.

7. Another important scenario: What if both machines produce equal quantities?
Let's change one condition.

Suppose:
- Machine 1 produces 25 wrenches/hour.
- Machine 2 produces 25 wrenches/hour.
- Overall defective rate = 1%.
- 50% of defective products come from each machine.
Now:
\[
P(M_1)=50\%
\]

\[
P(M_2)=50\%
\]

\[
P(D)=1\%
\]

\[
P(M_2|D)=50\%
\]

Apply Bayes' Theorem:
\[
P(D|M_2)=
\frac{0.50\times0.01}{0.50}
\]

\[
\boxed{P(D|M_2)=1\%}
\]

Here, the answer is 1% because both machines produce equal quantities and contribute equally to defective products.

Compare the two scenarios:
Condition	Machine 1	Machine 2	Defective rate from M2
Original example	30/hour	20/hour	1.25%
Equal production	25/hour	25/hour	1%

This demonstrates why we must understand the production distribution before calculating probabilities.

8. Difference between P(A|B) and P(B|A)
This is one of the most important concepts in Bayes' Theorem.

Consider our original machine example.
\[
P(M_2|D)=50\%
\]

Meaning:

Given that a wrench is defective, what is the probability that it came from Machine 2?

Answer: 50%.

Now:
\[
P(D|M_2)=1.25\%
\]

Meaning:

Given that a wrench came from Machine 2, what is the probability that it is defective?

Answer: 1.25%.

These probabilities are not the same.
Probability	Meaning	Result
\(P(M_2)\)	Product came from Machine 2	40%
\(P(D)\)	Product is defective	1%
\(P(M_2\|D)\)	Defective product came from Machine 2	50%
\(P(D\|M_2)\)	Machine 2 product is defective	1.25%

Remember: The order of events in conditional probability matters.









1. What is Naive Bayes?
Naive Bayes is a supervised machine learning algorithm used mainly for classification problems.

It is based on Bayes' Theorem, which we just studied.

Naive Bayes predicts the class of a new data point by calculating the probability that it belongs to each possible class.

In simple words:

Suppose you receive an email. You want to determine whether it is:
- Spam
- Not Spam
Naive Bayes examines the words in the email and calculates the probability that the email belongs to each category.

For example:

An email contains:

"Congratulations! You won free money. Claim your prize now."

Naive Bayes examines words such as:
- Congratulations
- Won
- Free
- Money
- Prize
If these words frequently appear in spam emails, the algorithm calculates a higher probability for the Spam class.

Therefore, it predicts that the email is Spam.

Naive Bayes is widely used in:
1. Spam email detection.
2. Sentiment analysis.
3. News classification.
4. Document categorization.
5. Text classification.
6. Medical diagnosis.
7. Recommendation and prediction systems.

2. Why is it called Naive Bayes?
Let's break the name into two parts.

Bayes:

It uses Bayes' Theorem to calculate probabilities.

Naive:

It makes a naive assumption that all features are conditionally independent of each other, given the class.

Let's understand this with an example.

Suppose we have an email containing three words:
- Free
- Money
- Offer
Naive Bayes assumes that these words are independent of each other when the email's class is already known.

For example:
\[
P(Free,Money,Offer|Spam)
\]

Under the Naive Bayes independence assumption:
\[
=P(Free|Spam)
\]

\[
\times P(Money|Spam)
\]

\[
\times P(Offer|Spam)
\]

This assumption simplifies the calculation significantly.

In reality, words can be related. For example, "Free" and "Offer" may frequently appear together. However,
Naive Bayes ignores that dependency to make the model computationally simple.

3. Mathematical formula of Naive Bayes
Remember the Bayes' Theorem formula:
\[
P(A|B)=\frac{P(B|A)\times P(A)}{P(B)}
\]

In Naive Bayes classification, we use:
\[
\boxed{P(Class|Features)}
\]

This means:

What is the probability that a particular data point belongs to a class given its features?

For multiple features, the formula becomes:
\[
P(C|X_1,X_2,\ldots,X_n)
\]

Using the Naive Bayes independence assumption:
\[
P(C|X_1,\ldots,X_n)
\propto
P(C)\prod_{i=1}^{n}P(X_i|C)
\]

Where:
Term	Meaning
\(C\)	Target class
\(X_1,X_2,\ldots,X_n\)	Input features
\(P(C)\)	Prior probability of the class
\(P(X_i\|C)\)	Probability of a feature given the class
\(\prod\)	Multiplication of all feature probabilities
\(P(C\|X_1,\ldots,X_n)\)	Posterior probability

Why do we use the proportional symbol \(\propto\)?

Because the evidence probability \(P(X_1,\ldots,X_n)\) is the same for every class when comparing classes for the same input.

Therefore, we can compare the unnormalized probabilities directly.

The class with the highest probability is selected.

5. What happens if a probability becomes zero?
This is a very important concept in Naive Bayes.

Suppose our training dataset contains no Spam email with the word "Meeting".

Then:
\[
P(Meeting|Spam)=\frac{0}{5}=0
\]

Now suppose a new email contains:
- Free = Yes
- Meeting = Yes
Our Spam probability calculation becomes:
\[
Score(Spam)=P(Spam)
\]

\[
\times P(Free|Spam)
\]

\[
\times P(Meeting|Spam)
\]

\[
=0.5\times0.8\times0
\]

\[
=0
\]

Even if every other word strongly indicates Spam, the entire score becomes zero.

This is called the Zero Frequency Problem.
Solution: Laplace Smoothing
Laplace smoothing solves this problem by adding a small value (usually 1) to the feature counts.

The formula is:
\[
P(X_i|C)=\frac{Count(X_i,C)+\alpha}
{Count(C)+\alpha K}
\]

Where:
- \(Count(X_i,C)\) = Number of occurrences of a feature in a class.
- \(Count(C)\) = Total observations in that class.
- \(\alpha\) = Smoothing parameter, usually 1.
- \(K\) = Number of possible feature values.
For our binary feature, K = 2 (Yes or No).

Suppose no Spam emails contain Meeting.

Without smoothing:
\[
P(Meeting=Yes|Spam)=\frac{0}{5}=0
\]

With Laplace smoothing:
\[
P(Meeting=Yes|Spam)=\frac{0+1}{5+(1\times2)}
\]

\[
=\frac{1}{7}
\]

\[
\boxed{P(Meeting=Yes|Spam)=0.1429}
\]

Now the probability is not zero.

This allows the model to consider other features instead of automatically assigning a zero score.

6. Types of Naive Bayes algorithms
There are three commonly used types of Naive Bayes classifiers.
1. Gaussian Naive Bayes

Used when features contain continuous numerical values and are modelled using a Gaussian (normal) distribution.

Example:
- Student marks.
- Employee salary.
- Height and weight.
- Temperature measurements.
The probability density is calculated using:
\[
P(x|C)=\frac{1}{\sqrt{2\pi\sigma^2}}
e^{-\frac{(x-\mu)^2}{2\sigma^2}}
\]

Where:
- \(\mu\) = Mean of the feature for that class.
- \(\sigma^2\) = Variance of the feature for that class.
- \(x\) = New observed value.


2. Multinomial Naive Bayes

Used mainly for discrete counts, especially word frequencies in text classification.

Example:

An email contains:
- Free = 3 times.
- Money = 2 times.
- Offer = 4 times.
The model uses these word counts to predict Spam or Not Spam.

Common applications:
- Spam detection.
- News categorization.
- Text classification.


3. Bernoulli Naive Bayes

Used when features are binary (Yes/No or 1/0).

Example:
Email	Free	Money	Offer
1	1	1	0
2	1	0	1
3	0	1	0

Here:
- 1 means the word exists.
- 0 means the word does not exist.
Common applications:
- Spam detection.
- Binary text classification.

1. What is Decision Tree Classification?
Decision Tree Classification is a supervised machine learning algorithm used to solve classification problems.

It predicts the class or category of a new data point by following a sequence of decisions based on its input features.

In simple words:

A Decision Tree works like a flowchart. It asks a series of questions and makes decisions based on the answers until it reaches a final prediction.

The decision tree might ask:
1. Is the customer's credit score greater than 700?
2. If yes, is their salary greater than NPR 50,000?
3. Based on the answers, should the loan be approved or rejected?
This is how a Decision Tree makes predictions.

Common applications:
1. Loan approval prediction.
2. Fraud detection.
3. Customer churn prediction.
4. Medical diagnosis.
5. Spam detection.
6. Employee attrition prediction.
7. Customer segmentation.

4. What is Entropy?
Entropy measures the impurity or randomness of a dataset.

In simple words:

Entropy tells us how mixed the classes are in a dataset.

For example, suppose we have 10 customers.

Scenario A:
- 5 customers have Approved loans.
- 5 customers have Rejected loans.
Both classes are equally distributed. The dataset is highly mixed.

Entropy is high.

Scenario B:
- 10 customers have Approved loans.
- 0 customers have Rejected loans.
All customers belong to the same class. The dataset is completely pure.

Entropy is zero.
Entropy formula
\[
Entropy(S)=-\sum_{i=1}^{n}p_i\log_2(p_i)
\]

For binary classification:
\[
\boxed{
H(S)=-p_1\log_2(p_1)-p_2\log_2(p_2)
}
\]

Where:
- \(p_1\) = Probability of the first class.
- \(p_2\) = Probability of the second class.
- \(H(S)\) = Entropy of the dataset.
Example 1: Calculate entropy when both classes are equal
Suppose we have 10 customers:
- Approved = 5.
- Rejected = 5.
Probability of Approved:
\[
P(Approved)=\frac{5}{10}=0.5
\]

Probability of Rejected:
\[
P(Rejected)=\frac{5}{10}=0.5
\]

Apply the formula:
\[
H(S)=-0.5\log_2(0.5)
\]

\[
-0.5\log_2(0.5)=0.5
\]

For both classes:
\[
H(S)=-(0.5\times-1)-(0.5\times-1)
\]

\[
\boxed{H(S)=1}
\]

Maximum impurity
Example 2: Calculate entropy when all customers belong to one class
Suppose:
- Approved = 10.
- Rejected = 0.
\[
P(Approved)=\frac{10}{10}=1
\]

\[
P(Rejected)=\frac{0}{10}=0
\]

Apply the formula:
\[
H(S)=-(1\times\log_2(1))
\]

\[
-(0\times\log_2(0))
\]

We define the zero-probability contribution as zero.

Therefore:
\[
\boxed{H(S)=0}
\]

Completely pure dataset
Entropy values to remember
Distribution	Entropy	Meaning
10 Approved, 0 Rejected	0	Completely pure
9 Approved, 1 Rejected	0.469	Very low impurity
8 Approved, 2 Rejected	0.722	Low impurity
7 Approved, 3 Rejected	0.881	Moderate impurity
5 Approved, 5 Rejected	1	Maximum impurity

For binary classification, entropy ranges from 0 to 1.

Remember:
- Entropy = 0 means all observations belong to one class.
- Entropy = 1 means both classes are equally distributed.
- Lower entropy means a purer dataset.

5. What is Information Gain?
Now we understand entropy.

But how does a Decision Tree select the best feature for splitting?

This is where Information Gain comes in.

Information Gain measures how much uncertainty is reduced after splitting a dataset using a particular feature.

In simple words:

It tells us how useful a feature is for separating different classes.
Information Gain formula
\[
\boxed{
IG=H(Parent)-H(Children)
}
\]

More precisely, because the child nodes can have different sizes:
\[
IG=H(S)-\sum_{j=1}^{k}
\frac{|S_j|}{|S|}H(S_j)
\]

Where:
- \(H(S)\) = Entropy before splitting.
- \(H(S_j)\) = Entropy of each child node.
- \(|S_j|\) = Number of observations in each child.
- \(|S|\) = Total number of observations.
The weighted child entropy is important because each child may contain a different number of observations.
Example: Information Gain using our loan dataset
Recall our dataset:

1	750	60,000	Approved
2	720	55,000	Approved
3	680	30,000	Rejected

8	690	45,000	Rejected
9	740	70,000	Approved
10	630	28,000	Rejected

We have:
- 5 Approved.
- 5 Rejected.
The parent entropy is:
\[
H(S)=1
\]

Now let's consider a possible split:

Credit Score greater than 700?

This creates two groups.

2	720	Approved

9	740	Approved

This group contains:
- Approved = 5.
- Rejected = 0.
Its entropy is:
\[
H(S_1)=0
\]

Group 2: Credit Score less than or equal to 700.
Customer	Credit Score	Loan Status

- Approved = 0.
- Rejected = 5.
Its entropy is:

H(S_2)=0
\]

Now calculate weighted child entropy:
\[
H(Children)=
\frac{5}{10}\times0+
\frac{5}{10}\times0
\]

\[
\boxed{H(Children)=0}
\]

Calculate Information Gain:
\[
IG=H(Parent)-H(Children)
\]

\]

\]

\]

The algorithm can select either one as the root feature.

Important: In a real dataset, the algorithm evaluates many possible splitting thresholds and selects the split that produces the highest Information Gain.

6. What is Gini Impurity?
Entropy is not the only method used by Decision Trees.

Another popular method is called Gini Impurity.

Gini Impurity measures how likely a randomly selected observation would be incorrectly classified if it were labelled according to the class distribution of the node.

In simple words:

It measures how mixed the classes are in a dataset.
Gini Impurity formula
\[
\boxed{Gini=1-\sum_{i=1}^{n}p_i^2}
\]

For binary classification:
\[
Gini=1-[P(Approved)^2+P(Rejected)^2]
\]

Example 1: Equal distribution
Suppose:
- Approved = 5.
- Rejected = 5.
\[
P(Approved)=0.5
\]

\[
P(Rejected)=0.5
\]

Apply the formula:
\[
Gini=1-(0.5^2+0.5^2)
\]

\[
=1-(0.25+0.25)
\]

\[
\boxed{Gini=0.5}
\]

Example 2: Completely pure dataset
Suppose:
- Approved = 10.
- Rejected = 0.
\[
Gini=1-(1^2+0^2)
\]

\[
\boxed{Gini=0}
\]

Entropy vs Gini Impurity
Feature	Entropy	Gini Impurity
Measures	Uncertainty	Impurity
Formula	\(-\sum p_i\log_2 p_i\)	\(1-\sum p_i^2\)
Pure node	0	0
Maximum for binary classification	1	0.5
Computation	Relatively more expensive	Relatively simpler

Both methods help a Decision Tree find good splits.

In Scikit-learn, the default splitting criterion for DecisionTreeClassifier is gini.

7. How does a Decision Tree build the complete tree?
Now let's connect everything.

A Decision Tree generally follows these steps:
1. Start with the complete dataset.

   Calculate the impurity of the parent node.
2. Evaluate available features and possible splits.

   For example, Credit Score greater than 700 or Salary greater than 50,000.
3. Calculate the impurity after each split.

   Calculate weighted entropy or weighted Gini impurity.
4. Select the best split.

   Choose the split with the highest Information Gain or lowest weighted impurity.
5. Repeat the process recursively.

   Continue splitting the resulting child nodes.
6. Stop when a stopping condition is reached.

   For example, the node becomes pure, the maximum depth is reached, or further splitting is not allowed.
Important: Decision Trees use recursion
The algorithm repeats the same process on each child node.

It doesn't simply select one feature and stop.

It continues until it reaches a leaf node or a configured stopping condition.

Random Forest Classification
Random Forest Classification Algorithm
Random Forest Classification is a supervised machine learning algorithm used to classify data into different
categories.

It is an ensemble learning algorithm because it combines multiple Decision Trees to make one final prediction.

Let's understand it step by step with a practical example.
1. What is Random Forest Classification?
Remember our previous topic, Decision Tree Classification?

A Decision Tree makes a prediction using a sequence of questions.

For example, suppose a bank wants to decide whether to approve or reject a loan.

A decision tree might ask:
- Is the credit score greater than 700?
- Is the salary greater than 50,000?
- Does the customer have a good repayment history?
Based on the answers, it predicts whether to approve the loan.

However, a single Decision Tree can make mistakes or overfit the training data.

Random Forest solves this problem by creating multiple Decision Trees and combining their predictions.

Imagine asking 100 different experts to make a decision. Each expert gives an opinion, and the
majority opinion becomes the final decision.



2. How does Random Forest work?
Let's assume we have a dataset containing information about customers.
Customer	Age	Salary	Loan Status
A	25	30,000	Rejected
B	35	60,000	Approved
C	45	80,000	Approved
D	22	25,000	Rejected
E	40	70,000	Approved
F	28	35,000	Rejected

We want to predict whether a new customer should receive a loan.

Random Forest works through the following steps.

Step 1: Create random samples (Bootstrap Sampling)

Random Forest creates multiple training datasets from the original dataset.

It randomly selects records, allowing the same record to be selected more than once.

For example:
Original dataset
A

B

C

D

E

F



Random samples for three trees
Tree 1
A, B, B, D, E, F

Tree 2
A, C, C, D, E, F

Tree 3
B, C, D, D, E, A


This technique is called Bootstrap Sampling.

Important: Sampling is done with replacement. That means after selecting a record, it can be selected again.


Step 2: Build multiple Decision Trees

Each sample is used to train a separate Decision Tree.
Training dataset

Tree 1
Approved


Tree 2
Rejected


Tree 3
Approved



Majority Voting
Approved
2 out of 3 trees predicted Approved


Each tree learns its own decision rules from its sample.

Step 3: Random Feature Selection

This is another important concept.

Suppose our dataset contains these features:
- Age
- Salary
- Credit Score
- Employment Years
- Existing Debt
In a normal Decision Tree, the algorithm considers all available features when selecting the best split.

But Random Forest introduces randomness by considering only a randomly selected subset of features at each split.

For example:
Tree	Features considered at a split
Tree 1	Age, Salary
Tree 2	Credit Score, Debt
Tree 3	Employment Years, Age
Tree 4	Salary, Credit Score

This makes the trees less correlated with each other.

Why is this important?

If every tree uses exactly the same features and follows very similar splits, they may make similar mistakes.

Random feature selection encourages diversity among trees.

Step 4: Final Prediction (Majority Voting)

Suppose we have five Decision Trees.

A new customer's details are:
- Age = 35
- Salary = 60,000
- Credit Score = 750
The trees make the following predictions:
Decision Tree	Prediction
Tree 1	Approved
Tree 2	Approved
Tree 3	Rejected
Tree 4	Approved
Tree 5	Rejected

Count the votes:
- Approved = 3
- Rejected = 2
Therefore:
Final prediction: Approved
The class with the most votes becomes the final prediction.
