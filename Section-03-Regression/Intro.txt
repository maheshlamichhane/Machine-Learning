Simple Linear Regression
y^ = b0 +b1X1
where
y^ = Dependent variable
b0 = y-intercept
b1 = slope coefficient
X1 = Independent variable


This is the most important concept in Linear Regression. Once you understand this, you will understand what actually happens inside regressor.fit() and regressor.predict().

Let's understand it mathematically, using a real example.
1. How does Machine Learning find the straight line?
Suppose you provide this training dataset:
Experience (X)	Salary (Y)
1	30,000
2	40,000
3	50,000
4	60,000
5	70,000

We want to find a straight line:
\[
y = mx+c
\]

But we don't know the values of m and c.

Machine Learning needs to calculate them.

The objective is to find the line that produces the smallest possible prediction errors across the training data.
2. How does it calculate m (slope) and c (intercept)?
Scikit-learn's LinearRegression uses a mathematical technique called Ordinary Least Squares.

It calculates the following:

Slope (m):
\[
m = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}
{\sum (x_i-\bar{x})^2}
\]

Intercept (c):
\[
c = \bar{y}-m\bar{x}
\]

Where:
- \(x_i\) = Individual experience value.
- \(y_i\) = Individual salary value.
- \(\bar{x}\) = Average experience.
- \(\bar{y}\) = Average salary.
Let's calculate them using our example.

Average experience:
\[
\bar{x} = \frac{1+2+3+4+5}{5}=3
\]

Average salary:
\[
\bar{y} = \frac{30000+40000+50000+60000+70000}{5}
=50000
\]

Substituting into the slope formula:
\[
m = \frac{100000}{10}=10000
\]

Now calculate the intercept:
\[
c = 50000-(10000\times3)
\]

\[
c=20000
\]

Calculated result
Our final equation is:
\[
\boxed{y=10000x+20000}
\]

This is the best-fit straight line for our training dataset.
3. What if the training data isn't perfectly aligned?
Consider a slightly different dataset:
Experience	Actual Salary
1	32,000
2	39,000
3	52,000
4	58,000
5	72,000

Now the data points don't form a perfect straight line.

Machine Learning calculates a line that minimizes the sum of squared differences between actual salaries and predicted salaries.

For each data point:
\[
Error = Actual\ Salary-Predicted\ Salary
\]

And:
\[
SSE = \sum Error^2
\]

Why square the errors?
- Negative errors become positive.
- Larger errors receive greater penalties.
- Errors cannot cancel each other out.
This is called the Least Squares Method.
4. How does it calculate test data?
Now comes the interesting part!

Suppose our model has already learned:
\[
y=10000x+20000
\]

We provide new test data:
Experience (X_test)
6
7
8

The model simply substitutes these values into the learned equation.

For X = 6:
\[
y=10000(6)+20000=80000
\]

For X = 7:
\[
y=10000(7)+20000=90000
\]

For X = 8:
\[
y=10000(8)+20000=100000
\]

Prediction results
Experience	Predicted salary
6 years	80,000
7 years	90,000
8 years	100,000

Assumptions of Linear Regression
i. Linearity(Linear relationship between Y and each X
ii. Homoscedasticity(Equal variance)
iii. Multivariate Normality(Normality of error distribution)
iv. Independence(of observations includes no autocorrelation)
v. Lack of multicollinearity(Predictors are not corrected with each other)
vi. The outlier check(This is not an assumption,but an "extra")


Statistical Significance:

Building a Model
i. All-in
ii. Backward Elimination

v. Score Comparison

here 2,3,4 are called stepwise regression


i. All-in
-> Prior knowledge
-> You have to
-> Preparing for backward elimination


ii. Backward Elimination
Step 1: -> Select a significance level to stay in the model(e.g SL = 0.05)
Step 2: -> Fit the full model with all possible predictors.
Step 3: -> Consider the predictor with the highest P-value. if P > SL, go to step 4, otherwise got to FIN
step 4: -> Remove the predictor
step 5: -> Fit model without this variable.
step 6: -> got to step 3 until condition satisfies

FIN: Keep the previous model

iii. Forward Selection
Step 1: -> Select a significance level to enter the model(e.g SL = 0.05)
Step 2: -> Fit all simple regression models y ~ xn Select the one with the lowest P-value.
Step 3: -> Keep this variable and fit all possible models with one extra predictor added to the
one(s) you already have.
Step 4: -> Consider the predictor with the lowest P-value. If P < SL, goto step 3, otherwise goto FIN

iv. Bidirectional Elimination
Step 1: -> Select a significance level to enter and to stay in the model
e.g SLENTER = 0.05, SLSTAY = 0.05
Step 2: -> Perform the next step of Forward Selection(new variable must have P < SLENTER to enter)
Step 3: -> Perform All steps of Backward Elimination(old variable must have P < SLSTAY to stay)
Step 4: -> No new variable can enter and no old variable can exit.

Note: Backward Elimination is the fastest approach

Evaluating Machine Learning Model

R-Squared (R²)
R-Squared is a metric used to evaluate how well a regression model explains the variation in the actual data.

In simple words:

It tells us how well our machine learning model's predictions fit the actual values.

For example, suppose you build a machine learning model to predict house prices.
Actual price	Predicted price
50 lakh	52 lakh
60 lakh	58 lakh
70 lakh	72 lakh
80 lakh	79 lakh

If predicted prices are close to actual prices, your model performs well and generally gets a higher R² score.
1. Understanding R² values
R² = 1.0
Perfect fit



Model predictions perfectly match actual values.


R² = 0.85
Good fit



Model explains 85% of the variation in the target values.


R² = 0.50
Moderate fit



Model explains 50% of the variation.


R² = 0.0
Poor fit



No improvement over predicting the average target value.


Important: R² can also be negative. This means your model performs worse than simply predicting the average actual value.
2. How is R² calculated?
The formula is:
\[
R^2 = 1-\frac{SS_{res}}{SS_{tot}}
\]

Where:
- \(SS_{res}\) = Sum of Squared Residuals (prediction errors).
- \(SS_{tot}\) = Total Sum of Squares (variation in actual values around their mean).
In simple terms:
- Smaller prediction errors → Higher R².
- Larger prediction errors → Lower R².












1. Problem with Traditional R-Squared (R²)
First, let's understand a problem with the traditional R² method.

Suppose you are building a machine learning model to predict house prices.

You use these independent variables:
- X1 = House size
- X2 = Number of bedrooms
- X3 = Location
- X4 = House age
Your model produces an R² score of 0.85.

Now, suppose you add another independent variable:

- X5 = House color

House color probably has very little relationship with house prices.

What happens to R² when you add another independent variable?

Here is the problem:

Traditional R² never decreases when you add more independent variables to a regression model, even if those variables are irrelevant.
Example: Adding more features
Model	Features	R² score
Model 1	2	0.75
Model 2	3	0.82
Model 3	4	0.89
Model 4	5	0.91

Illustrative example. The R² score increases as features are added, even if some features contribute very little.

So, you might think Model 4 is the best model because it has the highest R².

But that's not necessarily true!

You might be adding unnecessary independent variables that make the model more complex without providing meaningful predictive value.

This is one reason why we use Adjusted R-Squared.










2. What is Adjusted R-Squared?
Adjusted R-Squared is an improved version of traditional R-Squared that considers the number of independent variables used in the model.

It solves the problem of blindly rewarding a model for adding more features.

It considers two things:
1. How well the model explains the variation in the target variable.
2. How many independent variables are used to achieve that result.
Unlike traditional R², Adjusted R² can increase or decrease when you add a new independent variable.
3. Adjusted R² formula
\[
R^2_{adj}=1-(1-R^2)\frac{n-1}{n-k-1}
\]

Where:
- \(R^2\) = Traditional R-Squared.
- \(n\) = Number of observations (rows).
- \(k\) = Number of independent variables (features).
Let's understand the difference:
R²	Adjusted R²
Never decreases when adding features.	Can increase or decrease.
Does not penalize unnecessary features.	Penalizes unnecessary features.
Considers model fit.	Considers model fit and model complexity.
Useful for measuring explained variation.	Useful for comparing regression models with different numbers of features.

4. Simple numerical example
Suppose:
- Number of observations (n) = 100
- Number of independent variables (k) = 5
- Traditional R² = 0.85
Using the formula:
\[
R^2_{adj}=1-(1-0.85)\frac{100-1}{100-5-1}
\]

\[
=1-(0.15)\times\frac{99}{94}
\]

\[
=1-0.15798
\]

\[
\boxed{R^2_{adj}=0.842}
\]

Final results
0.850
Traditional R²

0.842
Adjusted R²


Adjusted R² is slightly lower because it accounts for the number of features used.
