Simple Linear Regression
y^ = b0 +b1X1
where
y^ = Dependent variable
b0 = y-intercept
b1 = slope coefficient
X1 = Independent variable


This is the most important concept in Linear Regression. Once you understand this, you will understand what actually happens inside regressor.fit() and regressor.predict().

Let's understand it mathematically, using a real example.
1. How does Machine Learning find the straight line?
Suppose you provide this training dataset:
Experience (X)	Salary (Y)
1	30,000
2	40,000
3	50,000
4	60,000
5	70,000

We want to find a straight line:
\[
y = mx+c
\]

But we don't know the values of m and c.

Machine Learning needs to calculate them.

The objective is to find the line that produces the smallest possible prediction errors across the training data.
2. How does it calculate m (slope) and c (intercept)?
Scikit-learn's LinearRegression uses a mathematical technique called Ordinary Least Squares.

It calculates the following:

Slope (m):
\[
m = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}
{\sum (x_i-\bar{x})^2}
\]

Intercept (c):
\[
c = \bar{y}-m\bar{x}
\]

Where:
- \(x_i\) = Individual experience value.
- \(y_i\) = Individual salary value.
- \(\bar{x}\) = Average experience.
- \(\bar{y}\) = Average salary.
Let's calculate them using our example.

Average experience:
\[
\bar{x} = \frac{1+2+3+4+5}{5}=3
\]

Average salary:
\[
\bar{y} = \frac{30000+40000+50000+60000+70000}{5}
=50000
\]

Substituting into the slope formula:
\[
m = \frac{100000}{10}=10000
\]

Now calculate the intercept:
\[
c = 50000-(10000\times3)
\]

\[
c=20000
\]

Calculated result
Our final equation is:
\[
\boxed{y=10000x+20000}
\]

This is the best-fit straight line for our training dataset.
3. What if the training data isn't perfectly aligned?
Consider a slightly different dataset:
Experience	Actual Salary
1	32,000
2	39,000
3	52,000
4	58,000
5	72,000

Now the data points don't form a perfect straight line.

Machine Learning calculates a line that minimizes the sum of squared differences between actual salaries and predicted salaries.

For each data point:
\[
Error = Actual\ Salary-Predicted\ Salary
\]

And:
\[
SSE = \sum Error^2
\]

Why square the errors?
- Negative errors become positive.
- Larger errors receive greater penalties.
- Errors cannot cancel each other out.
This is called the Least Squares Method.
4. How does it calculate test data?
Now comes the interesting part!

Suppose our model has already learned:
\[
y=10000x+20000
\]

We provide new test data:
Experience (X_test)
6
7
8

The model simply substitutes these values into the learned equation.

For X = 6:
\[
y=10000(6)+20000=80000
\]

For X = 7:
\[
y=10000(7)+20000=90000
\]

For X = 8:
\[
y=10000(8)+20000=100000
\]

Prediction results
Experience	Predicted salary
6 years	80,000
7 years	90,000
8 years	100,000

Multiple Linear Regression
y^ = b0 + b1X1 + b2X2 + ... + bnXn
y^ = Dependent variable
b0 = y-intercept(constant)
b1 = Slope coefficient1
X1 = independent variable1
b2 = Slope coefficient2
X2 = independent variable2
bn = Slope coefficientn
Xn = independent variablen


Assumptions of Linear Regression
i. Linearity(Linear relationship between Y and each X
ii. Homoscedasticity(Equal variance)
iii. Multivariate Normality(Normality of error distribution)
iv. Independence(of observations includes no autocorrelation)
v. Lack of multicollinearity(Predictors are not corrected with each other)
vi. The outlier check(This is not an assumption,but an "extra")


Statistical Significance:

Building a Model
i. All-in
ii. Backward Elimination
iii. Forward Selection
iv. Bidirectional Elimination
v. Score Comparison

here 2,3,4 are called stepwise regression


i. All-in
-> Prior knowledge
-> You have to
-> Preparing for backward elimination


ii. Backward Elimination
Step 1: -> Select a significance level to stay in the model(e.g SL = 0.05)
Step 2: -> Fit the full model with all possible predictors.
Step 3: -> Consider the predictor with the highest P-value. if P > SL, go to step 4, otherwise got to FIN
step 4: -> Remove the predictor
step 5: -> Fit model without this variable.
step 6: -> got to step 3 until condition satisfies

FIN: Keep the previous model

iii. Forward Selection
Step 1: -> Select a significance level to enter the model(e.g SL = 0.05)
Step 2: -> Fit all simple regression models y ~ xn Select the one with the lowest P-value.
Step 3: -> Keep this variable and fit all possible models with one extra predictor added to the
one(s) you already have.
Step 4: -> Consider the predictor with the lowest P-value. If P < SL, goto step 3, otherwise goto FIN

iv. Bidirectional Elimination
Step 1: -> Select a significance level to enter and to stay in the model
e.g SLENTER = 0.05, SLSTAY = 0.05
Step 2: -> Perform the next step of Forward Selection(new variable must have P < SLENTER to enter)
Step 3: -> Perform All steps of Backward Elimination(old variable must have P < SLSTAY to stay)
Step 4: -> No new variable can enter and no old variable can exit.

Note: Backward Elimination is the fastest approach
